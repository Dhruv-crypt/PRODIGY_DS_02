# 🚢 Titanic Dataset – Exploratory Data Analysis (EDA)

A data analysis project focused on exploring passenger data from the Titanic dataset to uncover patterns in demographics, ticket class, and travel behavior using Python.

---

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Titanic dataset to understand passenger characteristics such as age, gender, class distribution, and fare patterns.

The goal is to extract meaningful insights from raw data using visualization and statistical analysis.

---

## 📂 Dataset

* **Dataset:** Titanic Passenger Data
* **Rows:** 400+ passengers (test dataset)
* **Features:**

  * PassengerId
  * Pclass (Ticket Class)
  * Name
  * Sex
  * Age
  * SibSp (Siblings/Spouses aboard)
  * Parch (Parents/Children aboard)
  * Ticket
  * Fare
  * Cabin
  * Embarked (Port of Embarkation)

---

## 🔍 Key Analysis Performed

* Data Cleaning (handling missing values in Age, Cabin)
* Data preprocessing and feature understanding
* Univariate analysis (Age distribution, Fare distribution)
* Categorical analysis (Gender, Class, Embarked)
* Relationship analysis (Fare vs Class, Age vs Class)
* Outlier detection using boxplots
* Correlation analysis between numerical features

---

## 📈 Visualizations

* Histograms for age and fare distribution
* Bar charts for passenger class and gender distribution
* Box plots to identify outliers in fare and age
* Heatmap to analyze correlations
* Count plots for categorical comparisons

---

## 🚀 Key Insights

* Majority of passengers belonged to **3rd class**, indicating economic diversity
* **Fare distribution is highly skewed**, with few high-paying passengers
* Missing values are significant in **Cabin column**, indicating incomplete records
* Age distribution shows concentration in **young adults (20–40 years)**
* Passenger distribution varies across embarkation ports (S, C, Q)
